# How this tree was recovered

Target: `Black.exe`, 4,148,736 bytes, PE32+ GUI, Mono/.NET assembly.
Analysed with a disassembler only — **the binary was never executed** during recovery.

## Toolchain

| Step | Tool |
|---|---|
| Identification | `file`, string scan for `BSJB`, `Costura`, `v4.0.30319`, `.NETFramework,Version=v4.7.2` |
| Decompilation | .NET SDK 8.0.428 + `ilspycmd` 9.1.0.7988 (ICSharpCode.Decompiler) |
| Embedded DLL extraction | `IO::Uncompress::RawInflate` over the Costura manifest resources (raw deflate) |

Scratch work happened outside the repository, in `~/.capy/work/black-recover`.

## Why this was fully recoverable

Costura embeds dependencies but does not touch the main assembly. `Black.exe` is an ordinary, un-obfuscated
CIL assembly with complete metadata: type names, method names, field names, string literals, resource names
and designer code all survived the build. ILSpy therefore produces source that is structurally identical to
the original.

## Quality of the output

- **Method bodies, control flow, expressions, string literals**: exact — they are read straight from CIL.
- **Local variable names**: lost (no PDB was embedded). ILSpy invents `num`, `text`, `flag`, `array` names.
  This is the only systematic difference from the original sources; behaviour is unaffected.
- **Class/field/method names**: original, as emitted by the compiler.
- **`internal` vs `private`**: preserved where metadata carries it.
- **Form designer code**: intact, but merged into each form's `.cs` file instead of living in a separate
  `*.Designer.cs`. `InitializeComponent` is byte-for-byte the compiled version.
- **Comments and preprocessor branches**: gone. Nothing in the binary carries them.
- **`Properties/Resources.Designer.cs`, `Properties/Settings.Designer.cs`**: decompiled from the generated
  classes. The original `Resources.resx` held no members, and `Settings.settings` is not recoverable — its
  default values are preserved as `DefaultSettingValue` attributes on the designer properties.
- **`BlackSpammerXS.csproj` and `FodyWeavers.xml`**: **reconstructed**, not recovered. The original project
  file is not embedded in the output; the dependency set here was read from the assembly references and the
  Costura manifest, and the versions from the embedded DLLs' file versions.
- **`app.ico`**: recovered verbatim (it is a manifest resource).

## Assets

All per-form resources came back as `.resx` with their image payloads intact (base64 `System.Byte[]` /
serialized objects). No external config, database or data file exists — the application keeps its state in
`Settings` and in files it writes at runtime, so there was nothing else to extract.

## What was deliberately not committed as source for the build

- **Third-party assemblies** embedded by Costura: `Siticone.UI`, `Bunifu_UI_v1.52`, `Newtonsoft.Json`,
  `System.Reactive`, `Websocket.Client`, `WindowsInput`, `BrotliSharpLib`, plus the Microsoft BCL shims and
  `Costura`/`Fody` plumbing. Versions are recorded in [DEPENDENCIES.md](DEPENDENCIES.md); the binaries stay
  out of the tree because they belong to their vendors.
- **`Costura/AssemblyLoader.cs` and `ProcessedByFody.cs`**: code generated by Fody at build time, not source.
  They are kept for completeness in `recovered/fody-generated/` rather than in the compilable project.
- **`BlackVerifyNumber.dll`**: embedded plugin whose assembly metadata credits *BlackGriefing 2020*, not this
  project. Its decompiled source sits in `recovered/BlackVerifyNumber/`, outside `src/`, and must be supplied
  in `lib/` to build.

## Completeness check

`recovered/manifest.txt` lists the SHA-256 of every file the decompiler produced that is checked in here.
From the repository root, `sha256sum -c recovered/manifest.txt` confirms the tree is exactly what came out of
`Black.exe` and has not been edited since.

## What failed

Nothing in the main application assembly. The only unrecoverable pieces are the ones that never existed in
the binary: comments, original local names, the real `.csproj`, `Settings.settings`, and the source of the
commercial third-party UI libraries.
